# 1431 — Kids With the Greatest Number of Candies

- Plataforma: LeetCode
- [Ver problema](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)
- Linguagem: Java

## Ideia da solução

Encontrar a maior quantidade atual de doces e verificar, para cada criança, se os doces extras alcançam esse valor.
